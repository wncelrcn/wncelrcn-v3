# Next.js Portfolio Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold a correctly configured Next.js portfolio app (Tailwind + shadcn/ui + GSAP) with the routing, section, token, and animation foundations ready for the Figma design to be translated into.

**Architecture:** Next.js App Router with a scroll-driven home page (`app/page.tsx`) composing section components, plus a route group for standalone pages. GSAP is isolated behind reusable client wrappers in `components/animations/` using `@gsap/react`'s `useGSAP` for scoped, auto-cleaned animations. Design tokens live as CSS custom properties in `app/globals.css` (Tailwind v4 `@theme`), giving one source of truth that the Figma design maps into.

**Tech Stack:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · GSAP + `@gsap/react` (ScrollTrigger) · Vitest (one pure-logic unit) · npm.

## Global Constraints

- Package manager: **npm** (use `npm`/`npx`, never yarn/pnpm/bun).
- **TypeScript strict** mode (create-next-app default) — no `any` in authored code.
- **App Router**, no `src/` directory — `app/` lives at repo root.
- Import alias: **`@/*`** → repo root.
- **Tailwind CSS v4** — CSS-first. Design tokens declared in `app/globals.css` via `@theme`; do **not** create a `tailwind.config.ts` unless a tool requires it.
- **Theming: match Figma only.** No dark-mode toggle, no `next-themes`. Keep whatever single theme shadcn generates until Figma tokens replace it.
- All GSAP usage goes through wrappers in `components/animations/`; register plugins exactly once in `lib/animations/gsap.ts`.
- Every animation must honor `prefers-reduced-motion` (no motion when the user opts out).
- This plan covers **Phase 1 (scaffold) only.** Faithful Figma translation is a separate follow-on plan, gated on the Figma file URL.

- [ ] **Step 6: Implement the reduced-motion helper**

Create `lib/animations/prefers-reduced-motion.ts`:
```ts
/**
 * Returns true when the user has requested reduced motion.
 * Injectable `matchMedia` keeps this pure and testable; defaults to the
 * browser's window.matchMedia and safely returns false during SSR.
 */
export function prefersReducedMotion(
  matchMedia: typeof window.matchMedia | undefined = typeof window !== "undefined"
    ? window.matchMedia
    : undefined,
): boolean {
  if (!matchMedia) return false;
  return matchMedia("(prefers-reduced-motion: reduce)").matches;
}
```

### Task 4: Reusable animation wrappers

**Files:**

**Interfaces:**
- Consumes: `@/lib/animations/gsap` and `@/lib/animations/prefers-reduced-motion` from Task 3.
- Produces:
  - `Reveal` from `@/components/animations/Reveal` — props `{ children: ReactNode; className?: string; delay?: number; y?: number }`. Fades/rises children in on mount.
  - `ScrollReveal` from `@/components/animations/ScrollReveal` — props `{ children: ReactNode; className?: string; y?: number }`. Fades/rises children in when scrolled into view.
  - Both no-op the motion (set final state immediately) when `prefersReducedMotion()` is true.

- [ ] **Step 1: Create the on-mount Reveal wrapper**

Create `components/animations/Reveal.tsx`:
```tsx
"use client";

import { useRef, type ReactNode } from "react";
import { gsap, useGSAP } from "@/lib/animations/gsap";
import { prefersReducedMotion } from "@/lib/animations/prefers-reduced-motion";

interface RevealProps {
  children: ReactNode;
  className?: string;
  delay?: number;
  y?: number;
}

export function Reveal({ children, className, delay = 0, y = 24 }: RevealProps) {
  const ref = useRef<HTMLDivElement>(null);

  useGSAP(
    () => {
      if (!ref.current) return;
      if (prefersReducedMotion()) {
        gsap.set(ref.current, { opacity: 1, y: 0 });
        return;
      }
      gsap.from(ref.current, {
        opacity: 0,
        y,
        duration: 0.6,
        delay,
        ease: "power2.out",
      });
    },
    { scope: ref },
  );

  return (
    <div ref={ref} className={className}>
      {children}
    </div>
  );
}
```

- [ ] **Step 2: Create the scroll-triggered ScrollReveal wrapper**

Create `components/animations/ScrollReveal.tsx`:
```tsx
"use client";

import { useRef, type ReactNode } from "react";
import { gsap, useGSAP } from "@/lib/animations/gsap";
import { prefersReducedMotion } from "@/lib/animations/prefers-reduced-motion";

interface ScrollRevealProps {
  children: ReactNode;
  className?: string;
  y?: number;
}

export function ScrollReveal({ children, className, y = 40 }: ScrollRevealProps) {
  const ref = useRef<HTMLDivElement>(null);

  useGSAP(
    () => {
      if (!ref.current) return;
      if (prefersReducedMotion()) {
        gsap.set(ref.current, { opacity: 1, y: 0 });
        return;
      }
      gsap.from(ref.current, {
        opacity: 0,
        y,
        duration: 0.8,
        ease: "power2.out",
        scrollTrigger: {
          trigger: ref.current,
          start: "top 80%",
          toggleActions: "play none none none",
        },
      });
    },
    { scope: ref },
  );

  return (
    <div ref={ref} className={className}>
      {children}
    </div>
  );
}
```
